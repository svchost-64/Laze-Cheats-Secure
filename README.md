# Laze Cheats Secure

Refactor de seguridad de Laze Cheats con frontend, Cloudflare Worker, Cloudflare D1 y controles de acceso.

Consulta [README_SEGURIDAD.md](README_SEGURIDAD.md) para instrucciones de instalación, riesgos pendientes y configuración obligatoria. **No es un despliegue en producción.**

**Importante:** los pagos automáticos permanecen desactivados mientras no se haya auditado y corregido la integración de verificación bancaria.
